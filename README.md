# Tetris Perfect Clear Analysis

## Project Description

This project analyzes four-piece Tetris opening sequences
to investigate which combinations allow a Perfect Clear.

It uses descriptive statistics and machine learning to
identify patterns in successful and unsuccessful sequences.

## Research Questions

1. What proportion of possible opening sequences allow a Perfect Clear?
2. Which piece types and positions are most frequently associated with successful sequences?
3. Are certain combinations of tetrominoes more likely to produce a Perfect Clear?
4. Can a decision tree classifier predict whether a sequence will produce a Perfect Clear?

## Dataset

The dataset contains 840 possible sequences:
- 711 successful sequences
- 129 unsuccessful sequences

Source: https://swng.github.io/ttpc/
