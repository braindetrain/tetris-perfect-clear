# Data Dictionary

## Dataset Description

This dataset contains 840 possible four-piece Tetris sequences
from the TETRIS Perfect Clear Challenge.

Each row represents one possible sequence.

## Variables

| Variable | Description |
|---|---|
| piece_1 | First tetromino |
| piece_2 | Second tetromino |
| piece_3 | Third tetromino |
| piece_4 | Fourth tetromino |
| success | Whether the sequence permits a Perfect Clear (1 = Yes, 0 = No) |

## Dataset Statistics

- Total sequences: 840
- Successful sequences: 711
- Unsuccessful sequences: 129
